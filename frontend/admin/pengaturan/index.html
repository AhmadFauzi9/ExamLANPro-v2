Keamanan Ujian (Mode Kiosk Resmi)

Informasi proteksi layar siswa dan pintasan darurat proktor ruang.

Proteksi Mode Kiosk Klien:
  • Layar terkunci otomatis dalam mode layar penuh (Full Screen) saat siswa memulai ujian.
  • Jika siswa keluar layar penuh (tekan X atau tahan ESC), layar ujian langsung terkunci seketika dan pelanggaran dicatat ke server pengawas.
  • Pindah tab, membuka jendela lain, atau tombol Windows otomatis mengunci layar ujian.

Agar tombol X atas hilang total dan tombol ESC tahan mati sepenuhnya (standar ANBK), buka komputer siswa melalui Launcher Kiosk:

Pintasan Darurat Pengawas:
Rahasia
CTRL + C + B

Tekan kombinasi tombol di atas pada perangkat siswa untuk langsung keluar seketika dari Mode Kiosk atau membuka kunci layar yang terblokir. (Pintasan ini sengaja dirahasiakan dan tidak ditampilkan di layar komputer siswa).
